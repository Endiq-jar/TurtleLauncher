## 🌿 About TurtleLauncher

TurtleLauncher is an Android launcher for **Minecraft: Java Edition**, developed by **[Endiq](https://github.com/Endiq-jar)**.

Inspired by the possibilities of open-source Minecraft launchers, TurtleLauncher aims to bring a customizable, feature-rich Java Edition experience to Android devices.

From instance management and mod loaders to renderer options, Java runtimes, account management, and mobile-focused tools, TurtleLauncher brings together the features Minecraft players need in one place.

### ⚔️ Our vision

- 🎮 Make Minecraft: Java Edition more accessible on Android.
- 🌿 Deliver a clean, customizable launcher experience.
- 🧩 Support modded Minecraft and multiple game configurations.
- ⚡ Provide useful performance and runtime controls.
- 🛠️ Give players greater control over their installations.
- 💚 Build an open-source project that can grow with its community.

## ✨ Features

### 🎨 Modern interface

- Material Design 3 interface.
- Dynamic themes and accent colors.
- Dark mode.
- Smooth animations and screen transitions.
- Responsive phone and tablet layouts.
- Gaming-inspired visual design.
- Custom backgrounds and UI scaling.

### ⚡ Performance and runtime controls

- Performance-focused launcher improvements.
- JVM and RAM configuration.
- Java runtime management.
- Renderer selection and configuration.
- MobileGlues renderer settings.
- Mesa3D and LTW renderer integrations.
- Launch and crash log inspection.

*Actual performance depends on device hardware, Android version, game version, renderer, drivers, mods, and configuration.*

### 🎮 Minecraft and mod-loader support

- Minecraft release versions.
- Snapshot, Beta, and Alpha versions where supported.
- Fabric.
- Quilt.
- Forge.
- NeoForge.
- Cleanroom integration.
- Multiple game instances.

*Compatibility varies by Minecraft version and loader. Check the current release and project documentation for supported configurations.*

### 📦 Content management

Manage supported Minecraft content from the launcher:

- Mods.
- Resource packs.
- Shader packs.
- Datapacks.
- Worlds.
- Screenshots.
- Logs.
- Modpack instances.
- Skin and cape management.

### ☕ Java management

- Manage compatible Java runtimes.
- Manual Java 8, 17, 21, and 25 downloads where supported.
- Package-signature checks for supported download workflows.
- Runtime selection for compatible Minecraft versions.
- JVM argument and memory configuration.

Not every Java version works with every Minecraft release. Select a runtime compatible with the game version and installed mods.

### 🔐 Account management

- Microsoft account integration.
- Offline accounts.
- Battly account integration.
- Ely.by account integration.
- Account management and supported authentication workflows.

Authentication availability and requirements depend on the selected provider and the current launcher implementation.

### 🛠️ Launcher tools

- Download Manager.
- Live launch logs.
- Crash diagnostics.
- Backup, import, and export.
- Content descriptions, galleries, versions, and changelogs where available.
- Customizable Discord Rich Presence, including version templates, status, timer, and artwork.
- In-game LWJGL tinyfd / NFD file-manager integration.
- Terracotta integration for supported multiplayer workflows.
- Friends and LAN play through Terracotta over EasyTier, including home-screen hosting and joining.
- App-wide screen transitions: slide, bounce, fade, and zoom.
- Emotes.
- Beryllium integration.

### 🔓 Optional Shizuku support

TurtleLauncher can use Shizuku-compatible functionality on supported Android devices.

Depending on the device, Android version, permissions, and implementation, this can include:

- One-tap permission assistance.
- All-files access and notification permission assistance.
- Battery-exemption assistance.
- Game process priority adjustments.
- Android 14+ phantom-process limit handling.
- System logcat access for diagnostics.
- Compatibility with Shizuku and Sui.

**Shizuku is optional.** Its availability and the permissions it can grant depend on Android restrictions, setup, and device configuration. TurtleLauncher can be used without it.

### 🎨 Customization and in-game tools

- Custom launcher backgrounds.
- UI scaling.
- Animation controls.
- Performance profiles.
- JVM and RAM settings.
- Renderer settings.
- In-game Dark Mode resource pack.

The in-game Dark Mode resource pack is intended to darken supported menus, buttons, and containers. The supplied implementation provides a toggle through the in-game Debug tab and resource-pack reload behavior.

## 📥 Installation

### Option 1 — Download a release

1. Open the [TurtleLauncher Releases](https://github.com/Endiq-jar/TurtleLauncher/releases) page.
2. Select the release you want to install.
3. Download the APK asset provided by that release.
4. Open the downloaded APK on your Android device.
5. Follow Android's installation prompts.

Only install APKs from sources you trust. Review release notes and verify available checksums or signatures when provided.

### Option 2 — Build from source

Developers can explore the repository and its build configuration:

1. Open the [TurtleLauncher repository](https://github.com/Endiq-jar/TurtleLauncher).
2. Read the project's build instructions and Gradle configuration.
3. Install the required Android development tools and compatible JDK.
4. Build using the project's documented Gradle tasks.
5. Install the resulting APK on a compatible test device.

The exact build commands and requirements depend on the current repository configuration.

## ❓ FAQ

<details>
  <summary><strong>🛡️ Is TurtleLauncher safe?</strong></summary>

  TurtleLauncher is an open-source project. You can inspect its source code and report potential security issues through GitHub. No software can be guaranteed completely risk-free.

  Download releases only from sources you trust.

</details>

<details>
  <summary><strong>💚 Is TurtleLauncher free?</strong></summary>

  TurtleLauncher is distributed as an open-source project under the license specified in this repository. Check the official release page for downloads.

</details>

<details>
  <summary><strong>🧩 Does TurtleLauncher support Minecraft mods?</strong></summary>

  TurtleLauncher includes support for selected mod loaders and content-management workflows. Compatibility depends on the Minecraft version, loader, mod, runtime, and graphics environment.

</details>

<details>
  <summary><strong>☕ Which Java versions are supported?</strong></summary>

  Java 8, 17, 21, and 25 download workflows are listed among the project's features. The appropriate runtime depends on the Minecraft version and installed components.

</details>

<details>
  <summary><strong>📱 Does TurtleLauncher work on every Android device?</strong></summary>

  No launcher can guarantee compatibility with every device. Results depend on Android version, CPU architecture, available memory, graphics drivers, renderer, and game configuration.

</details>

<details>
  <summary><strong>🔓 Is Shizuku required?</strong></summary>

  No. Shizuku is optional. Some additional permissions or system-level features may require a compatible Shizuku or Sui setup.

</details>

<details>
  <summary><strong>🔐 Do I need a Microsoft account?</strong></summary>

  TurtleLauncher lists Microsoft, offline, Battly, and Ely.by account workflows. The requirements depend on the selected account provider and the current implementation. Offline accounts do not grant ownership of paid Minecraft features or bypass official authentication requirements.

</details>

<details>
  <summary><strong>🐛 Where can I report bugs?</strong></summary>

  Open an issue on GitHub and include:

  - Your Android version and device architecture.
  - The Minecraft version and Java runtime.
  - The selected renderer and mod loader.
  - Steps to reproduce the problem.
  - Relevant launch or crash logs.

  **[Open GitHub Issues →](https://github.com/Endiq-jar/TurtleLauncher/issues)**

</details>
