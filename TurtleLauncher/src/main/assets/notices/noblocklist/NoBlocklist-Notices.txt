NoBlocklist 1.0
===============
A simple Java agent that prevents the Mojang blocked servers list from loading.
Project: https://github.com/MojoLauncher/NoBlocklist (by artdeell / MojoLauncher)
Upstream prebuilt jar: NoBlocklist-1.0-SNAPSHOT-all.jar (release "1.0").

Bundled here as assets/components/components/NoBlocklist.jar and passed to the
game as -javaagent when Settings > Game > NoBlocklist is enabled (default on).
Set it off there if you would rather run completely vanilla.

This copy was rebuilt from the upstream 1.0 tag sources by
tools/build_noblocklist.py (the release download was unreachable from the build
sandbox). Differences from the upstream prebuilt jar:
  * Random.nextInt(1000, 1100) (Java 17+) replaced by 1000 + nextInt(100) so
    the agent also works on the Java 8 runtime used for Minecraft < 1.17.
  * TestMain (upstream test harness) is not included.
  * ASM is the core-ASM copy already bundled in this repository's
    authlib-injector.jar, relocated to git.artdeell.shasm exactly like
    upstream's Shadow build.
To use the untouched upstream jar instead, download it from the releases page
above, replace NoBlocklist.jar, and bump assets/components/components/version.
