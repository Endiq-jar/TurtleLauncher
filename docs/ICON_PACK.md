# Downloadable TurtleLauncher icon concepts

## Download the ready-made ZIP

[Download 2,048 icons + the original (approximately 20 MB)](../downloads/TurtleLauncher-2048-icons-plus-original.zip)

On GitHub, open the file and click **Download raw file** to save the ZIP.
Extract it and open `index.html` to browse the icons offline.

`tools/generate_turtle_icon_pack.py` draws 2,048 new pixel-art turtle icons,
inspired by the existing launcher icon. It does **not** replace app resources.
The existing `mipmap-xxxhdpi/ic_launcher.png` is included byte-for-byte as the
original, together with the repository's full turtle WebP artwork.

## Reproduce

```sh
python3 -m venv /home/user/.venv
/home/user/.venv/bin/pip install Pillow
/home/user/.venv/bin/python tools/generate_turtle_icon_pack.py
```

Outputs (intentionally under ignored `release/`):

- `release/TurtleLauncher-2048-icons-plus-original.zip`
- `release/turtle-icon-pack/index.html`: searchable offline gallery
- `release/turtle-icon-pack/PREVIEW.jpg`: 64 representative samples
- `png/`: 2,048 512 × 512 PNGs
- `svg/`: matching scalable, pixel-geometry SVGs, no embedded bitmaps
- `original/`: unmodified repository originals
- CSV and JSON manifests with design parameters and uniqueness hashes

The designs vary geometry, side/top views, walking/swimming poses, shell
patterns, accessories, 16 color themes and eight background motifs. A seeded
PRNG makes reproduction deterministic. Every image and foreground alpha-mask
silhouette must have a unique SHA-256 hash; the generator fails on duplicates.
The manifest records both hashes. This is exact geometric uniqueness, not a
claim that every design is perceptually unrelated to all other turtle designs.

The generator validates ZIP integrity, PNG/SVG counts, and byte-for-byte
preservation of the original PNG. Generated PNGs have opaque square backgrounds;
this is an artwork collection, not an Android adaptive-icon installation pack.
New images are procedurally drawn with Pillow, not generated by an image model.
The repository license is included in the archive; no separate trademark rights
are granted.
